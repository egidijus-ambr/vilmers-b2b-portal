Flow Summary

Happy path: User fills reference in stepper step → clicks Add to Cart → item added directly
Lazy path: User skips reference in stepper → clicks Add to Cart → modal appears → must enter reference → confirm adds item
Modal cancel: Returns to configurator, nothing added
Validation: "Add to Cart" button in modal is disabled until reference is non-empty
